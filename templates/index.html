TrailTrap Help

About

TrailTrap is a cloud deception and threat monitoring dashboard. It monitors AWS CloudTrail activity, detects interactions with honey IAM users and honey buckets, enriches attacker IPs using AbuseIPDB, and visualizes findings in real time.

Severity Levels

  • Critical - Abuse Score ≥ 75
  • High - Abuse Score 25-74
  • Medium - Abuse Score < 25

Dashboard Controls

  • 🔄 Refresh - Reload latest findings
  • 🔍 Search - Search by user, IP, event or country
  • 🎯 Filter - Filter by severity, country or IAM user
  • 📄 Export CSV - Download all findings

Data Sources

AWS CloudTrail • AbuseIPDB • Flask • Chart.js
